# Guia de soporte inicial

## Categorias

- Error de pago.
- Error de orden.
- Problema de catalogo.
- Problema de empresa.
- Problema de usuario.
- Problema de servicio tecnico.
- Problema de ubicacion.
- Problema de stock.

## Datos minimos por caso

- Usuario afectado.
- Modulo.
- Fecha y hora.
- Captura o evidencia.
- ID de orden, pago, producto o caso tecnico.
- Estado esperado.
- Estado observado.

## Criterio operativo

Los pagos, cambios de estado, aprobaciones y suspensiones deben revisarse contra auditoria antes de corregir manualmente datos.
